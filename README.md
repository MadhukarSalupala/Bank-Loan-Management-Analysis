# Bank Loan Management and Analysis

## Project Overview

Bank Loan Management and Analysis is a MySQL-based data analysis project designed to analyze customer loans, loan types, branches, and loan payments.

The project demonstrates advanced SQL concepts commonly used in Data Analyst roles.

## Database Tables

- Customers
- Loans
- Loan Types
- Branches
- Loan Payments

## SQL Concepts Used

- Joins
- Subqueries
- CTEs
- Window Functions
- Views
- Stored Procedures
- Aggregate Functions
- CASE Statements

## Key Analysis

The project analyzes:

- Customer loan details
- Loan amounts and statuses
- Loan types and interest rates
- Branch-wise loan performance
- Customer-wise loan analysis
- Loan payment information
- High-value loans
- Customer and loan rankings

## Tools Used

- MySQL
- MySQL Workbench
- GitHub
